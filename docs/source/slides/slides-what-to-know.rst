Key terms 📝
------------


+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Term             | Symbol | Explanation                                                                                                                       |
+==================+========+===================================================================================================================================+
| **Slide design**                                                                                                                                              |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Slide            |        | A page in a slide deck                                                                                                            |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Slide deck       |        | A collection of slides. ("Deck" as in a `deck of cards`)                                                                          |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Layout           |        | A visual plan for the appearance and location of elements for a slide                                                             |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Theme            |        | A collection of layouts                                                                                                           |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Master layout    |        | The primary layout of a theme that defines all the other layouts in the theme.                                                    |
|                  |        | (Can also be called the ‘parent’ layout, with the individual layouts being called the ‘child’ layouts.)                           |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Theme builder    |        | The tool for viewing and editing the layouts in a theme                                                                           |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| **Graphic design objects**                                                                                                                                    |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Shape            |        |                                                                                                                                   |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Line             |        |                                                                                                                                   |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Connector        |        | Lines that attach to shapes and change shape dynamically when the connected object changes                                        |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Word art         |        | Used to create text that can be freely resized and treated like a vector object                                                   |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Border           |        |                                                                                                                                   |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Drop shadow      |        | Context shadow behind objects and images. Makes the element look like it is floating above the slide’s background                 |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Reflection       |        |                                                                                                                                   |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| **Graphic design tools**                                                                                                                                      |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Crop             |        | Cut off part of an image from one of the four sides                                                                               |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Mask             |        | Cut off part of an image based on a shape                                                                                         |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Order            |        | Change the ordering (layering) of objects on a slide. Objects in the front appear on top of others.                               |
|                  |        | Objects at the back appear behind others.                                                                                         |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Align            |        | Change how objects are aligned (lined up) with each other. Objects can be aligned to the:                                         |
|                  |        |  - Left, centre, or right                                                                                                         |
|                  |        |  - Top, middle, or bottom                                                                                                         |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Distribute       |        | Change how objects are distributed (spaced out) relative to each other. Objects can be distributed:                               |
|                  |        |  - Horizontally                                                                                                                   |
|                  |        |  - Vertically                                                                                                                     |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Rotate           |        | Rotate an object around its centre                                                                                                |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Flip             |        | Flip an object horizontally or vertically                                                                                         |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Group            |        | Combine a collection of objects (on the same slide) into a group. The group can then be moved and edited together.                |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| **Motion graphics**                                                                                                                                           |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Animation        |        | Animated motion of objects within a slide                                                                                         |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+
| Transition       |        | Animated motion of an entire slide, played when moving from the previous slide to the current slide                               |
+------------------+--------+-----------------------------------------------------------------------------------------------------------------------------------+

Keyboard shortcuts ⌨️
---------------------

+===============================================+=============================+============================+
| Action                                        | PC Keyboard                 | Mac keyboard               |
+===============================================+=============================+============================+
| **When an object is selected on a slide**                                                                |
+-----------------------------------------------+-----------------------------+----------------------------+
| Move object                                   | ``↑,↓,←,→``                 | ``↑,↓,←,→``                |
+-----------------------------------------------+-----------------------------+----------------------------+
| Change order, resize, rotate, etc.            | ``Ctrl + ↑,↓,←,→``          | ``⌘ + ↑,↓,←,→``           |
| (Actions vary by software)                    |                             |                            |
+-----------------------------------------------+-----------------------------+----------------------------+
| Select all objects on current slide           | ``Ctrl + A``                | ``⌘ + A``                 |
+-----------------------------------------------+-----------------------------+----------------------------+
| **When a slide is selected in the side preview pane**                                                    |
+-----------------------------------------------+-----------------------------+----------------------------+
| Move to previous, next slide                  | ``↑,↓``                     | ``↑,↓``                    |
+-----------------------------------------------+-----------------------------+----------------------------+
| Change order of current slide                 | ``Ctrl + ↑,↓``              | ``⌘ + Home / End (?)``    |
+-----------------------------------------------+-----------------------------+----------------------------+
| Select all slides                             | ``Ctrl + A``                | ``⌘ + A``                 |
+-----------------------------------------------+-----------------------------+----------------------------+

Mouse shortcuts 🐀
------------------

+=======================================================+======================+======================+
| Action                                                | Symbol               | Mouse                |
+=======================================================+======================+======================+
| **While clicking and dragging from the centre of an object**                                        |
+-------------------------------------------------------+----------------------+----------------------+
| Copy object                                           |                      | ``Ctrl + drag``      |
+-------------------------------------------------------+----------------------+----------------------+
| Move object along cardinal directions only            |                      | ``Shift + drag``     |
+-------------------------------------------------------+----------------------+----------------------+
| Prevent object from snapping to guidelines            |                      | ``Alt + drag``       |
+-------------------------------------------------------+----------------------+----------------------+
| **While clicking and dragging the resize handles on edges of objects**                              |
+-------------------------------------------------------+----------------------+----------------------+
| Mirrored resize                                       |                      | ``Ctrl + drag``      |
| This means resizing an object based on its centre                            |                      |
| instead of its edge                                                                                 |
+-------------------------------------------------------+----------------------+----------------------+
| Prevent object from snapping to guidelines            |                      | ``Alt + drag``       |
